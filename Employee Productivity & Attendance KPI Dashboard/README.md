# Employee Productivity & Attendance KPI Dashboard

Built an interactive Excel dashboard to monitor employee productivity, attendance, and active working hours for Direct Upload Proofers. The dashboard uses KPI metrics, conditional formatting, and performance categorization to identify employee performance levels efficiently.

Features:
Employee-wise productivity tracking
Attendance and active hours monitoring
KPI-based performance analysis
Conditional formatting indicators for quick insights:
🔴 Red → Productivity = 0 & Attendance = Present
🟢 Green → Productivity < 50% & Attendance = Present
🔵 Blue → Productivity between 50%–80% & Attendance = Present
🟣 Purple → Productivity between 80%–100% & Attendance = Present
Automated counting of employees under each performance category
Interactive and easy-to-read dashboard design
