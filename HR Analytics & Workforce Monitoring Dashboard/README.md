# HR Analytics & Workforce Monitoring Dashboard

This project is a comprehensive Power BI HR Dashboard developed to help HR and management teams track, analyze, and monitor workforce-related KPIs in real time.

The dashboard provides insights into:

* Employee Headcount Trends
* Budget vs Actual Headcount
* Talent Acquisition & DUP Conversion Tracking
* Gender & Age-wise Workforce Distribution
* PM vs TM Workforce Analysis
* Tenure Analysis
* Attrition Monitoring
* Employee Pulse & Engagement Tracking
* Capacity Planned vs Actual Workforce
