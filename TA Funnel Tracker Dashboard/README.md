# TA Funnel Tracker Dashboard

Description:

Designed and developed an interactive Talent Acquisition analytics dashboard in Power BI to monitor recruiter productivity, hiring funnel performance, and sourcing efficiency. The dashboard tracks candidate progress across multiple recruitment stages including HR screening, technical rounds, shortlist conversion, and offers. Integrated dynamic filters, KPI cards, drill-down matrix views, and weekly trend analysis to help recruitment teams make data-driven hiring decisions.

Tech Stack
* Power BI
* DAX
* Power Query
* Data Modeling
* Excel / CSV Data Sources
